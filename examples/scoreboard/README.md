# AnimatedScoreboard

Shows `%ainexus_cached_survival_tips%` on an AnimatedScoreboard. Install the prompt first: [placeholders](../placeholders/README.md). PlaceholderAPI must be installed.

## Paste

Save `tips.yml` as `plugins/AnimatedScoreboard/scoreboards/tips.yml`. The file name is the scoreboard name. The `display` list is AnimatedScoreboard's compact form: the first entry is the title, and each later entry is a line. Lines that contain a placeholder refresh with the board.

This fragment does not replace `plugins/NexusAI/config.yml`.
